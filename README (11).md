- ODIN — linha de entrega do método, com link para a edição mais recente
- Links do ecossistema: [hubstry.dev](https://www.hubstry.dev) · [overall720.xyz](https://www.overall720.xyz)

## Stack

HTML estático autocontido (sem build) — pronto para GitHub Pages, Render ou qualquer hospedagem estática.

## Deploy

1. Suba o arquivo HTML como `index.html` na raiz (ou em `/docs`) do repositório.
2. Em **Settings → Pages**, selecione a branch e a pasta correspondente.
3. O site fica disponível em `https://<usuario>.github.io/<repo>/`.
